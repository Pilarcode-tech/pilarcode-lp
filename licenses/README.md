# Third-party UI components

The adapted components in `app/components/ui/` originate from Magic UI (MIT), discovered via the 21st.dev community library. The original license is retained in `magic-ui.txt`.

- Shine Border by Dillion Verma: https://21st.dev/@dillionverma/components/shine-border
- Interactive Hover Button (original credit: Aayush Bharti): https://magicui.design/docs/components/interactive-hover-button
- Bento Grid: https://magicui.design/docs/components/bento-grid
- Upstream source: https://github.com/magicuidesign/magicui/tree/main/apps/www/registry/magicui

Adaptations use the Pilarcode palette and existing fonts, remove external icon/helper dependencies, retain visible content on keyboard/touch, and respect reduced motion. Project artwork is original conceptual vector illustration, not a product screenshot or an official client logo.

## Kokonut UI

`app/components/ui/background-paths.tsx` is adapted from Background Paths v2.0.0 by Dorian Baffier / Kokonut UI (MIT), selected from https://21st.dev/@kokonutd/components/background-paths. Original source: https://kokonutui.com/r/background-paths.json. The license is retained in `kokonut-ui.txt`. Pilarcode supplies its own content and palette, with reduced line count and flow speed.

## Brand assets

The logo cloud is an original implementation informed by the 21st.dev Logo Cloud examples. Brand relationships and the founder portrait were supplied/authorized by the site owner. Natura, Usaflex and Havanna are explicitly described as brands operated by a franchise group served by Pilarcode.

Asset references: Moretão Produções and Natura artwork from https://www.moretaoproducoes.com.br/brand/moretao_transparente.webp and https://www.moretaoproducoes.com.br/clients/Natura.webp; Usaflex from its official storefront header (usaflextatix.vtexassets.com); Havanna from https://institucional.havanna.com.br/wp-content/uploads/2021/12/Logo-3@2x.png; Sucalog from its official high-resolution asset https://sucalog.com.br/wp-content/uploads/2020/08/Sucalog-Logo-PNG.png. Fieldis is displayed as text only, per the owner's brand guidance.

## Selected hero

The final hero uses the Shape Landing Hero / Shape Hero v1.0.0 composition from Kokonut UI, selected at https://21st.dev/@kokonutd/components/shape-landing-hero. Upstream source: https://github.com/kokonut-labs/kokonutui/blob/83eec6d982d400a18438001a8efdbac1f159dd43/components/kokonutui/shape-hero.tsx. Its geometric layering, entrance and floating animations are preserved using CSS. Colors, fonts and content follow Pilarcode. The existing Kokonut UI MIT notice applies.

# Third-party UI components

The adapted components in `app/components/ui/` originate from Magic UI (MIT), discovered via the 21st.dev community library. The original license is retained in `magic-ui.txt`.

- Shine Border by Dillion Verma: https://21st.dev/@dillionverma/components/shine-border
- Interactive Hover Button (original credit: Aayush Bharti): https://magicui.design/docs/components/interactive-hover-button
- Bento Grid: https://magicui.design/docs/components/bento-grid
- Upstream source: https://github.com/magicuidesign/magicui/tree/main/apps/www/registry/magicui

Adaptations use the Pilarcode palette and existing fonts, remove external icon/helper dependencies, retain visible content on keyboard/touch, and respect reduced motion. Project artwork is original conceptual vector illustration, not a product screenshot or an official client logo.

## Kokonut UI

`app/components/ui/background-paths.tsx` is adapted from Background Paths v2.0.0 by Dorian Baffier / Kokonut UI (MIT), selected from https://21st.dev/@kokonutd/components/background-paths. Original source: https://kokonutui.com/r/background-paths.json. The license is retained in `kokonut-ui.txt`. Pilarcode supplies its own content and palette, with reduced line count and flow speed.
